# debiased-oblique-projections
Anonymous release of the main experimental code for the submitted paper.


### Contents
For fast CUR decomposition, the comparison results are obtained using:
- `bias_cur_sketch_size_cifar_10.py`
- `cur_sketch_size_cifar_10_osp.py`
- `cur_variance_sketch_size_cifar_10.py`
- `solvers_cur.py`
- `solvers_cur_bias.py`
- `solvers_cur_corss_u.py`
- `sketches_cur.py`

For subsampled OLS, the comparison results are obtained using:
- `ols_variance_sketch_size_msd.py`
- `ols_bias_sketch_size_msd.py`
- `sketches.py`
- `solvers_lr.py`
- `solvers_lr_bias.py`
